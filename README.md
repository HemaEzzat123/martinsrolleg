# 🌀 Martins Rolleg - Premium Cinnamon Rolls & Gourmet Bakery Website

Martins Rolleg is a luxury, production-ready, fully responsive restaurant web application built for a premium cinnamon roll and bakery brand across the Middle East (Riyadh, Dubai, Abu Dhabi, Jeddah, Dammam).

## 🚀 Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 + Custom Theme System
- **Routing**: React Router DOM v7 (with `React.lazy` code splitting)
- **Animations**: Framer Motion
- **Icons**: React Icons (Feather Icons, FontAwesome, Simple Icons)
- **Carousels**: Swiper.js
- **Form Management**: React Hook Form with full validation

## 📱 Pages Included

1. **Home**: Hero banner with animated stats counter, Best Sellers, Why Choose Us grid, Bakery Gallery with Lightbox, Testimonials Swiper, Instagram feed, and FAQ accordion.
2. **Menu**: Filterable catalog (Cinnamon Rolls, Donuts, Waffles, Coffee, Cold Drinks) with search, sorting, and Quick View detail modal.
3. **Catering**: Event packages for Corporate Events, Birthdays, Universities, Schools, & Private Events with a full `CateringForm`.
4. **Franchise**: Investment landing page with ROI benefits, support & training overview, 5-step timeline, and `FranchiseForm`.
5. **B2B Wholesale**: Commercial partnership page targeting Hotels, Cafes, Restaurants, Offices & Retail Chains with `B2BForm`.
6. **Feedback**: Customer rating page with interactive star rating picker, branch select, order number, and `FeedbackForm`.
7. **Careers (التقديم على الوظائف)**: Bilingual team application page with job positions, drag-and-drop PDF resume uploader, and field validation.
8. **Contact**: Interactive multi-branch selector (Riyadh, Dubai, Abu Dhabi, Jeddah, Dammam) with details, working hours, embedded Google Map, and `ContactForm`.
9. **404 Page**: Custom bakery error page.

## 💻 Getting Started Locally

1. Clone the repository:
```bash
git clone https://github.com/HemaEzzat123/martinsrolleg.git
cd martinsrolleg
```

2. Install dependencies:
```bash
npm install
```

3. Run development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
